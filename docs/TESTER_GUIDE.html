Section

Sell

📦

Products

Create and manage products you sell. Each product holds the value prop, ICP, differentiators, and proof points the AI uses when generating scripts.

Product List

Grid of all products. Click to open detail view; Edit and Duplicate buttons on each card. Product name is the primary identifier.

Product Form

Multi-field form for creating/editing a product. Required: Name, One-liner, Description. Other fields are recommended but optional. AI-assist buttons can auto-fill fields.

Product Detail

Read-only detail page showing all product fields. Actions: Edit, Duplicate, Delete, Generate Script (opens Call Studio pre-filled).

🎙

Call Studio

The script generation cockpit. Pick a product, then configure the call and hit Generate.

Script Configuration

Step-by-step form: Call Type → Methodology → Duration → Language → Region → Delivery Style → Persona. Each combination produces a unique saved script.

callTypemethoddurationlanguageregiondeliverysimplepersona

Live Cockpit

After generation, the script opens in a live call cockpit with time-segmented script sections, objection bank, and a live timer. Scripts are saved automatically — refreshing the page returns to the same script.

📋

Scripts

Saved scripts data table with sorting, filtering, search, campaign tags, drag-and-drop priority, pagination, and bulk actions.

Table View

Columns: #, Script name, Method, Type, Duration, Language, Region, Style, Campaign, Outcome, Last updated. Sortable columns. Column selector to show/hide. Checkbox for bulk selection. Sr. No. is continuous across pages.

Filters & Search

Filter panel: Product, Method, Language, Outcome, Campaign, Date range. Active filter chips show what's applied. KPI bar shows total scripts, win rate, and outcome counts — clicking a KPI filters to that outcome.

Pagination & Ordering

Rows per page: 10, 20, 50, 100 (saved to localStorage). Page number buttons with ellipsis. "Sort by priority" toggle enables drag-and-drop reordering. Campaign column is inline-editable.

Bulk Actions

Select multiple scripts → Export details, Sync missing languages (generates the same script for each team language), or Delete in bulk.

Voice DNA

Add company materials (pitch decks, emails, call recordings, brand guides) and the AI extracts a Voice DNA profile — tone, vocabulary, style, guidelines. Toggle it on to influence all generated scripts.

Authentication

Auth & Accounts

Register

Email + password (min 6 chars). Company name is optional. Creates a workspace with the user as admin.

email *password *company_name

Login

Returns a JWT token stored in localStorage. Token expires in 7 days. All API calls include Authorization: Bearer <token>.

Session Restore

On page load, if a token exists, /api/auth/me is called to verify it. If valid, the user is auto-logged in. If expired, the token is cleared and the user sees the login screen.

Key testing point: Unauthenticated users see only the login screen. Any direct API call without a valid token returns 401. The canGenerate permission check gates script generation, coaching, and call analysis endpoints.

Checklist

What to Test

🔐

Auth & Navigation

• Register → auto-login → dashboard
• Login with wrong password → error
• Refresh page → stays on same view (not dashboard)
• Unauthenticated access → redirects to login
• Sidebar navigation between all views

📦

Products CRUD

• Create product with required fields only
• Edit product → changes persist
• Duplicate product → creates copy
• Delete product → confirmation → removed
• AI-assist buttons fill fields correctly

🎙

Script Generation

• Generate script for each call type × method combo
• Same combo → returns existing script (no duplicate)
• Voice DNA toggle ON → script follows company voice
• Voice DNA toggle OFF → neutral voice
• Script saves automatically on generation

📋

Scripts Table

• Sr. No. (#) is continuous across pages
• Pagination: change rows per page (10/20/50/100) → persists on refresh
• Filter by product, method, language, outcome, campaign, date
• Sort by any column; priority sort enables drag reorder
• Campaign inline-edit → saves to API
• Bulk select → export, sync languages, delete

🧬

Voice DNA

• Upload recording → Deepgram transcribes → saved as doc
• Add text document → appears in list
• Search/filter/sort documents
• Analyze → structured profile appears
• Toggle ON/OFF → persists per workspace
• Self-Improvement is separate (not affected by Voice DNA)

✍️

Required Fields

Every required field has a red asterisk (*) with no gap between label and asterisk. Check all forms:
• Login: Email*, Password*
• Products: Name*, One-liner*, Description*
• Voice DNA: Doc name*, Type*, Content*
• Scheduled Calls: All 7 fields are required
• Competitors: Name*, Category*, Website*, Product*, Content*

📞

Call Analysis

• Upload audio → Deepgram STT → transcript appears
• Paste transcript manually
• Analysis generates adherence score + feedback
• Past analyses: search, sort, filter
• Delete analysis → confirmation → removed

⚡

Edge Cases

• Empty states: no products, no scripts, no team members
• Very long product names and descriptions
• Special characters in form inputs
• Concurrent users: same product, different outcomes
• Network failure during script generation → error state
• JWT expiry → auto-redirect to login

Quick start: npm install && npm run dev starts both Vite (port 5173) and Express (port 3001). Register a new account, create a product, and generate your first script.
